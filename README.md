# Java Collections and Library Management System

This repository contains Java programs based on the Collections Framework and Object-Oriented Programming concepts.

## Programs Included

1. **studentlist.java** – Stores and displays student names using ArrayList.
2. **studentmap.java** – Stores roll numbers and student names using HashMap.
3. **sortt.java** – Sorts numbers using Collections.sort().
4. **LibraryManagementSystem.java** – Implements a mini Library Management System using OOP and File Handling.
5. **ProjectReport.md** – Contains the project report explaining the Library Management System logic.

## Concepts Covered

- ArrayList
- HashMap
- Collections Framework
- Sorting
- Classes and Objects
- Object-Oriented Programming
- File Handling
- File Reading and Writing

## Project Features

- Add books
- Display books
- Search books
- Issue books
- Return books
- Save book records in a text file

## Language Used
Java

## Purpose
To practise Java Collections, OOP and File Handling through basic programs and a mini-project.
